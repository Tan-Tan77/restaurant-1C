
Самописная конфигурация 1С для работы ресторана.
Включает в себя:
1. Технологические карты блюд
2. Расчёт остатков по продуктам 
3. Отчёты по продажам блюд, работы официантов, расчётам с поставщиками
4. Систему подарочных сертификатов и скидочных карт
5. Печатные формы для чеков и сертификатов
6. Начисление заработной платы и премии официантам
